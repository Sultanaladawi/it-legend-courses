## 🌟 نظرة عامة على المشروع (Project Overview)

تم بناء هذا المشروع لتقديم تجربة تعليمية تفاعلية متكاملة تحاكي منصات التعليم العالمية الكبرى ومطابقة لتصميم **Figma** المعتمد للتحدي بالمليمتر (Pixel-Faithful Implementation)، مع مراعاة أعلى معايير هندسة البرمجيات وتجربة المستخدم (UX/UI) والأداء السريع.

المشروع يتضمن صفحتين رئيسيتين متجاوبتين بالكامل (Responsive across Mobile, Tablet, and Desktop):
1. **صفحة عرض الكورسات (`/` - Courses Listing Page):**  
   - استعراض 6 دورات تدريبية متخصصة ومصنفة.
   - فلترة ديناميكية حسب المسار (Frontend, Backend, Cybersecurity, Database, DevOps).
   - فلترة حسب حالة الدورة (الكل، قيد المتابعة، مكتملة، جديدة).
   - شريط بحث فوري بالاسم، الوصف، أو المحاضر.
   - إحصائيات الإنجاز والنقاط وساعات التعلم.
   - بطاقات تفاعلية تعرض شريط التقدم، تقييم المحاضر، مدة الدورة، مع زر توجيه ديناميكي (استكمل الدورة / ابدأ الآن / مراجعة).

2. **صفحة مشغل الكورس (`/courses/[id]` - Course Player Experience):**  
   - **مشغل فيديو متطور (Custom Video Player Engine):**
     - شريط تحكم كامل (تشغيل/إيقاف، تمرير التايم لاين، كتم وتعديل الصوت).
     - تسريع وإبطاء الفيديو (0.75x, 1x, 1.25x, 1.5x, 1.75x, 2x).
     - **وضع المسرح والشاشة العريضة (Theater / Wide Mode):** يتيح تمديد الفيديو بعرض كامل مع نقل القائمة الجانبية أسفل المشغل بسلاسة تامة.
     - وضع ملء الشاشة (Fullscreen API).
     - أزرار التنقل التلقائي بين الدروس (Previous / Next Lessons).
     - **ميزة تثبيت الفيديو على الموبايل (Sticky Video on Mobile):** عند التمرير لأسفل على الشاشات الصغيرة، يظل مشغل الفيديو مثبتاً في أعلى الشاشة لمتابعة الشرح أثناء استعراض محتوى الدروس أو النقاشات.
   - **قائمة الدروس التفاعلية (Curriculum & Playlist Sidebar):**
     - أكورديون للفصول مع إمكانية الفتح والطي.
     - تحديد الدروس كمكتملة تفاعلياً وتحديث نسبة إنجاز الدورة لحظياً.
     - مؤشر بصري مميز للدرس الجاري تشغيله حالياً مع حركة بصرية نابضة.
   - **تبويبات المحتوى (Course Tabs):**
     - **نظرة عامة (Overview):** ملخص الدورة، بيانات المدرب، وماذا سيتعلم الطالب.
     - **المواد والملحقات (Materials):** قائمة ملفات الـ PDF والمرفقات مع إمكانية التحميل وعرض المستند.
     - **الامتحان والتقييم (Exam):** كويز شامل لقياس المهارات.
     - **الأسئلة والنقاشات (Q&A):** مجتمع تفاعلي، نظام إعجابات، وإضافة تعليقات سريعة.
     - **لوحة المتصدرين (Leaderboard):** ترتيب الطلاب حسب نقاط الخبرة (XP) مع إبراز حساب الطالب الحالي.
   - **النوافذ المنبثقة التفاعلية (Interactive Modals):**
     - **نافذة طرح الأسئلة (Ask Question Modal):** مزودة بميزة **الحفظ التلقائي للمسودات (Auto-draft to `localStorage`)** لحماية استفسار الطالب من الضياع في حال إغلاق النافذة أو انقطاع الاتصال واسترجاعه فورياً.
     - **عارض ملفات الـ PDF (PDF Viewer Modal):** نافذة منبثقة تفاعلية تتيح تصفح المستند، التحكم في نسبة التكبير/التصغير (Zoom In/Out)، والتنقل بين الصفحات.
     - **نافذة الامتحان التفاعلي (Interactive Exam Modal):** عداد زمني تنازلي، أسئلة باختيار من متعدد، تصحيح فوري، واحتساب درجة النجاح مع مراجعة الإجابات الصحيحة.

## 🏗️ القرارات المعمارية وهندسة الكود (Architecture Decisions)

### 1. Next.js App Router (Server vs. Client Components)
- **Server Components:**
  - تم استخدام Server Components في صفحة `src/app/courses/[id]/page.tsx` لتوليد الميتا داتا الديناميكية (`generateMetadata`) واستخراج المعاملات عبر `generateStaticParams` لضمان أقصى سرعة في بناء الصفحات وتحسين محركات البحث (SEO).
- **Client Components (`"use client"`):**
  - تم عزل المنطق التفاعلي (مشغل الفيديو، حالة الفصول، مسودات `localStorage`، النوافذ المنبثقة، وتغيير التبويبات) داخل مكونات عميل نقية ومستقلة (`CoursePlayerClient`, `VideoPlayer`, `CourseTabs`, `Modals`) لمنع أي تحميل زائد غير ضروري على حزمة الجافاسكريبت.

### 2. إدارة الحالة (State Management)
- الاعتماد على **React State** المحلي مع **Compound Components** دون الحاجة لمكتبات ثقيلة خارجية غير مبررة، مما جعل التطبيق فائق الخفة والسرعة.
- مزامنة إتمام الدروس وتحديث شريط نسبة التقدم تلقائياً عبر جميع مكونات الصفحة.
- استخدام `localStorage` لتأمين تجربة المستخدم ومنع فقدان البيانات غير المحفوظة في النوافذ المنبثقة.

### 3. دعم كامل للغة العربية والاتجاه (Full RTL & Typography)
- ضبط اتجاه الصفحة بالكامل `dir="rtl"` في `layout.tsx`.
- دمج خط **Cairo** المتميز من Google Fonts لضمان وضوح النصوص ومطابقتها لهوية التصميم العربي الأصيل.
- تصميم متوافق مع مبدأ **Mobile-First** وخالٍ تماماً من التمرير الأفقي غير المرغوب فيه (Zero Horizontal Scroll).

## 🛠️ متطلبات التشغيل والتشغيل المحلي (Getting Started)

### 1. المتطلبات الأساسية
- **Node.js** إصدار 18.18+ أو 20+ أو 24+.
- مدير الحزم **npm** أو **pnpm** أو **yarn**.

### 2. التثبيت والتشغيل
```bash
# الانتقال لمجلد المشروع
cd it-legend-courses

# تثبيت الحزم التابعة
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

### 3. بناء نسخة الإنتاج واختبارها (Production Build)
```bash
npm run build
npm run start
```
